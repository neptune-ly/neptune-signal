# Contributing

Neptune. Signal changes must preserve the standard.

## Rules

- Keep standard changes separate from demo changes.
- Update version notes when public behavior changes.
- Do not add emoji to product UI.
- Do not introduce one-off colors outside tokens.
- Add RTL/LTR guidance for new components.
- Add KMP mapping for new components.
- Add accessibility rules for icon-only actions.

## Review Checklist

- Tokens updated.
- Docs updated.
- KMP notes updated.
- Figma notes updated.
- Accessibility reviewed.
- White-label behavior reviewed.
