# Typography Optical Refinement

Status: Active

## Problem

Visual quality must come from typography and hierarchy before effects.

## Rules

- One dominant type moment per screen.
- Balance and amount numerics use tabular alignment.
- Labels stay restrained.
- Section titles are clear but not loud.
- Arabic and Latin typography share role sizes but require optical review.
- Critical values never truncate with vague ellipsis.

## Banking Typography Priorities

- Balance: highest financial emphasis.
- Account/card names: strong but secondary.
- IBAN/reference/voucher values: readable and copyable.
- Metadata: quiet and truncatable only when non-critical.

## CTA Typography

CTA text should be confident, not oversized. Button emphasis comes from placement, fill, and action clarity, not just huge type.
