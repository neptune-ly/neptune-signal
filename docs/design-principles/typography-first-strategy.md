# Typography First Strategy

Date: 2026-05-15

## Principle

Neptune. Signal quality should come primarily from typography, spacing, and hierarchy. Visual effects are supporting tools only.

## Rules

- Financial values use tabular numerics and the strongest type hierarchy on the surface.
- Labels stay calm and secondary.
- Headlines should be confident without becoming marketing copy inside the app.
- Critical banking values are readable, copyable, and stable.
- No screen may solve weak hierarchy by adding decoration.

## Application

Onboarding uses headline rhythm and CTA choreography. Home uses balance/account hierarchy. Receipts and status pages use exact value presentation. Cards and account details use large financial anchors only where the user explicitly opened detail.
