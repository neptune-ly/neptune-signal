# Prism Account Card Language

The account card is the financial hero.

It may use the Prism account gradient or a bank override gradient. It should support crisp balance hierarchy, softer decimals, readable currency, status chips, IBAN containment, carousel indicators, and optional balance mask motion.

Allowed:
- Controlled gradient.
- Subtle inner highlight.
- Soft depth.
- Light sweep on carousel change.

Not allowed:
- Random background geometry.
- Decorative circles behind financial text.
- Crypto patterns.
- Low contrast text.
- Noisy overlays.

The account card must remain the strongest visual anchor on Home.
