# Tonal Layering Study

Status: Active

## Problem

The previous pass used gradients and atmospheric circles as depth. That is too synthetic.

## Correct Tonal Stack

| Plane | Role | Treatment |
| --- | --- | --- |
| Canvas | app background | neutral token fill |
| Group | sections and docks | soft tonal fill |
| Hero | account/card/payment source | stronger bank-primary surface |
| Action | money movement | bank-secondary or bank-primary solid fill |
| State | risk/success/pending | semantic color only |

## Rules

- Do not put decorative gradients behind every screen.
- Do not use floating brand blobs.
- Use one high-emphasis surface per screen.
- Use neutral dominance.
- Use accent sparingly.
- Let typography and spacing carry most hierarchy.

## Dark/OLED

Dark modes should use tonal separation instead of shadow or glow. Black mode must not become a field of unrelated black cards; surfaces should remain legible through carefully stepped tones.
