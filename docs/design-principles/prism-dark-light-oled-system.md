# Prism Dark / Light / OLED System

Prism has three primary appearance modes.

Prism Dark:
- Default flagship.
- Deep navy / ink base.
- Visible but controlled gradients.
- Floating surfaces and luminous accents.
- Excellent Arabic financial readability.

Prism Light:
- Frosted off-white base.
- Mist surfaces and soft ambient gradients.
- Crisp text and restrained accent usage.
- Premium daylight feel, not plain white Material.

Prism OLED:
- Near-black base.
- Reduced gradients and glow.
- Higher contrast and lower tint.
- Subtle luminance edges, no muddy green/blue surfaces.

Each mode is designed independently. No mode is a simple inversion of another.
