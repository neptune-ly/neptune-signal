# Spacing Rhythm Audit

Status: Active

## Problem

Uniform spacing can make banking screens feel mechanical. Overly decorative spacing can make them feel fake. Neptune needs controlled rhythm.

## Rules

- Use proximity to group related banking tasks.
- Use larger gaps only between conceptual zones.
- Keep account hero and payment action close enough to feel related.
- Keep recent activity visually calmer than the financial hero.
- Use edge gutters consistently.
- Avoid nested cards that create false grouping.

## Dashboard Rhythm

Recommended order:

1. Customer/session identity.
2. Account hero.
3. Payment action or payment dock.
4. Secondary actions.
5. Insight.
6. Activity.

## Quality Check

The user should understand the home screen in under three seconds:

- what account is selected,
- what the balance/state is,
- where to move money,
- what happened recently.
