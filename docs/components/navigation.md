# Component: Navigation

## Root Navigation

Root mobile navigation has four items:

- Home.
- Accounts.
- Cards.
- More.

## Nested Navigation

Nested pages:

- Keep the active root.
- Show a back action in the top app bar.
- Do not add temporary actions to bottom navigation.

## Direction

Back and next arrows must flip in RTL.

## Future Large-Screen Navigation

Internet banking should use:

- Sidebar or rail.
- Top utility bar.
- Breadcrumbs for complex flows.
- Persistent search where useful.
