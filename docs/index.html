Standard vs SDKs

The standard is not a demo and not one code library. It defines the design contract. SDKs implement that contract for each technology stack.

Signal StandardPlatform-neutral rules for tokens, components, motion, accessibility, content, and banking patterns.Version: 0.1.0
KMP SDKFirst implementation target for Compose Multiplatform and shared mobile UI.Status: active start
Flutter SDKFuture implementation package for Flutter products.Status: planned
Native SDKsFuture SwiftUI and Android Compose native packages.Status: planned
Web SDKFuture React/Web Components package for internet banking and portals.Status: planned
