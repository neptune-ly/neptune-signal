# Rejected Pattern: Wallet Reference Cloning

Date: 2026-05-15

## Rejection

Do not copy the preview-only e-wallet reference.

## Why

Neptune. Signal is a white-label fintech banking system, not a static concept shot. Cloning a reference creates:

- weak brand ownership,
- fragile implementation,
- one-off visual decisions,
- poor RTL confidence,
- poor dark-mode portability,
- inconsistent bank theming.

## What Is Allowed

Extract structural principles:

- tonal layering,
- smooth surface hierarchy,
- central money action,
- wallet-style dashboard flow,
- calmer spacing rhythm,
- restrained premium motion.

## What Is Not Allowed

- copied layout composition,
- copied card graphics,
- copied gradients,
- copied icon style,
- copied copywriting,
- decorative glow,
- crypto-style lighting,
- fake glass effects,
- bottom nav that hides banking root labels.
