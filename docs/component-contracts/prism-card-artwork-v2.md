# Prism Card Artwork V2

`SignalPrismCardArtworkProfile` defines the card surface:
- scheme
- Prism personality
- bank palette
- background style
- mark style
- typography style

Background styles include `Flat`, `SoftGradient`, `PremiumDark`, `FrostedLight`, `BankBrand`, and `MinimalCorporate`.

Gradients are allowed only when they improve identity. Flat and bank-branded surfaces are first-class Prism styles.
