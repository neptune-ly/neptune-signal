# Semantic Financial Color Contract

Financial color is semantic and sparse.

Rules:
- Primary: product action and banking emphasis.
- Success/green: money-in, completion, positive state.
- Warning/amber: attention, pending, required action.
- Error/red: failed, debit/error/destructive.
- Surface roles carry most grouping and hierarchy.

Expressive profiles adjust tone subtly; they do not repaint every module.

May 16 correction:
- Payment primary is no longer green by default.
- Quick transfer no longer uses a yellow/tertiary fill.
- Home timeline urgency is represented by one semantic marker instead of many colored dots.
