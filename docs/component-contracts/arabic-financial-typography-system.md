# Arabic Financial Typography System

Arabic-first Prism UI must not feel like mirrored LTR. Arabic labels keep natural RTL flow, while financial identifiers remain directionally stable.

Rules:
- Amounts use tabular numerics where available.
- PAN, IBAN, account IDs, references, and Latin aliases render LTR inside RTL context.
- Metadata uses medium weights and tighter visual volume.
- Section titles should guide scanning without competing with balances or primary actions.
