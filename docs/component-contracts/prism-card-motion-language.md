# Prism Card Motion Language

Allowed:
- Carousel snap.
- Soft card scale/tilt on entry.
- Light sweep on selection.
- Mask/unmask fade.
- Secure reveal sheet entrance.
- Card detail hero transition.

Not allowed:
- Constant shimmer.
- Aggressive 3D flip.
- Chaotic gradient animation.
- Idle pulsing cards.

Motion must communicate secure state changes, not decoration.
