# Prism Card Status System

Supported states:
- Active
- Frozen
- Blocked
- Expired
- Pending activation
- Virtual only
- Physical shipping
- Lost/stolen

Visual behavior:
- Active: normal Prism.
- Frozen: cool/desaturated with clear badge.
- Blocked: muted warning.
- Expired: neutral with action prompt.
- Pending/shipping: soft pending state.
- Lost/stolen: serious warning without panic styling.
