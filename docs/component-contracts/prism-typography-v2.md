# Prism Typography V2

Prism typography separates financial hierarchy from generic text:
- `PrismDisplayFinancial`
- `PrismTitleHero`
- `PrismTitleSection`
- `PrismTitleCard`
- `PrismBodyPrimary`
- `PrismBodySecondary`
- `PrismMeta`
- `PrismNavLabel`
- `PrismAmountLarge`
- `PrismAmountCompact`
- `PrismIdentifier`
- `PrismCardPan`
- `PrismCardMeta`
- `PrismStatus`

Metadata is calmer, titles are strong but less over-bold, and identifiers use tabular numerics with LTR direction inside RTL layouts.
