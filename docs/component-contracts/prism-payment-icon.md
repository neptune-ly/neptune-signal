# Prism Payment Icon

`SignalPrismPaymentIcon` replaces the paper-plane-like center action mark.

Direction:
- Payment / wallet / send-money hybrid.
- Geometric and readable at 28-30dp.
- No childish paper plane, no complex currency mark, no generic transfer arrow.

Current implementation draws a compact wallet outline with a directional payment arrow and small payment point. It is code-native so banks can recolor it through Prism content color.
