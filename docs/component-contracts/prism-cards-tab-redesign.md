# Prism Cards Tab Redesign

The Cards tab is a wallet surface, not a list of cards.

Structure:
1. Top context: title/subtitle via canonical top bar or page title.
2. Prism card carousel.
3. Four primary card actions.
4. Card status / limits summary.
5. Recent card activity preview.
6. Optional card benefits/offers later.

Rules:
- Do not show more than four primary actions above the fold.
- Card carousel owns the visual energy.
- Actions and limits support backend availability flags.
- Cards can be virtual, physical, frozen, blocked, expired, pending, or shipping.
