# Expressive Wallet Actions Contract

Purpose:
- Make Home shortcuts feel tactile and wallet-native without adding extra features or decorative cards.

Contract:
- Retail Home shows exactly four actions.
- The first action may be subtly featured when it is high-frequency and utility-oriented.
- Featured treatment uses size, shape, and a low-alpha primary container, not bright fills or gradients.
- Secondary actions stay readable but lighter, so the action cluster feels grouped instead of tiled.
- Press feedback uses a small scale response only.

Current actions:
- `الفواتير` / `دفع سريع`
- `رمز QR` / `استلام أو مسح`
- `المفضلة` / `مستفيدون محفوظون`
- `القسائم` / `متجر رقمي`

Rejected:
- More than four Home actions.
- Corporate, vPOS, VAS, or admin shortcuts on Retail Home.
- Heavy icon wells repeated on every cell.
