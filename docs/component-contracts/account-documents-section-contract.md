# Account Documents Section Contract

Documents are account-scoped downloadable or requestable records:
- statement PDF
- balance certificate
- account ownership proof
- fee/tax documents where available

Rows show title, description, availability, and action. Download/approval state is supplied by Nova/backend.
# Account Documents Section Contract

The documents segment groups account documents separately from the main overview.

Examples:

- كشف حساب PDF
- شهادة رصيد
- إثبات حساب
- ملخص رسوم

Rows should be compact, actionable, and backend-driven. If a document requires approval, the state is shown in metadata instead of creating a separate modal-first flow.
