# Expressive Financial Insights Contract

Purpose:
- Insight/status should feel intelligent, not like separate dashboard widgets.

Contract:
- One smart insight title.
- One explanation line.
- Up to two compact financial status metrics.
- Metrics use label, value, and status detail.
- The module may use stronger shape and a subtle leading treatment, but not multiple cards.

Current Home copy:
- `مصروفاتك أعلى بـ 12%`
- `الخدمات والبطاقات هي السبب الرئيسي`
- `فاتورة قادمة / 95.000 د.ل / خلال 3 أيام`
- `مدفوعات دورية / 2 نشطة / راجع الاشتراكات`
