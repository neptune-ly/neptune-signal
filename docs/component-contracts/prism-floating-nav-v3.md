# Prism Floating Nav V3

The Prism dock is a physical floating control surface, not glass. It may use a soft sheen and shadow, but the dock container must be opaque enough that scrolling content never bleeds through labels, icons, or the center payment action.

Appearance rules:
- Dark: near-opaque deep ink/navy dock, subtle edge highlight, restrained shadow.
- Light: near-opaque frosted/off-white dock, soft shadow, no thick outline.
- OLED: near-black dock, minimal luminance edge, no content bleed.

The center payment action remains elevated, but sits close enough to the dock to read as part of the navigation architecture.
