# Account Requests Section Contract

Requests are account-scoped operational actions, such as:
- request card
- certified cheque
- chequebook
- statement or balance certificates
- disputes

Tiles show title, short description, status, and action. Dangerous actions must be visually separated in a later production pass.
# Account Requests Section Contract

The requests segment exposes account-specific service requests without turning the workspace into a settings list.

Examples:

- request card
- certified cheque
- chequebook
- balance certificate
- account statement
- dispute or complaint

Each request provides title, short description, status, and an app-resolved action.
