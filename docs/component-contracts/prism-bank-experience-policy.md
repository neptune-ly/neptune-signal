# Prism Bank Experience Policy

`SignalPrismBankExperiencePolicy` represents the bank/client configuration layer.

It controls:
- bank identity
- palette
- default personality
- allowed user moods
- allowed card modes
- allowed nav styles
- default home layout
- motion/gradient/card/campaign profiles
- user personalization policy

The bank profile is authoritative; Neptune Prism is the fallback identity, not a forced style.
