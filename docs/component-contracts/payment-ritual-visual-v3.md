# Payment Ritual Visual V3

Concept:
- Secure Seal Morph plus Receipt Emergence.

Contract:
- Processing uses one focal verification object.
- The object breathes subtly during active phases.
- Terminal states stop the breathing motion and resolve to success, pending, or failure.
- Lifecycle rails are opt-in, not default.
- Receipt/result surfaces carry the post-completion closure.

Rejected:
- Dot swarms.
- Spinners.
- Pointer animations.
- Busy route-node systems.
- Old hourglass treatment.
