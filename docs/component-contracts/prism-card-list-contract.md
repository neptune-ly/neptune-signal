# Prism Card List Contract

`SignalPrismCardList` provides a premium list-mode alternative to carousel browsing.

Each row includes:
- mini card artwork or scheme mark
- card name
- scheme
- masked PAN / last4
- status
- balance or limit summary
- physical/virtual indicator

The row is tappable and opens card details. List mode is intended for banks and users who prefer clarity over swipe interaction.
