# Prism Account Card Artwork

Prism account cards use controlled gradient, soft edge light, typography, and subtle motion.

Allowed:
- Low-noise gradient.
- Inner highlight edge.
- Protected IBAN strip.
- Status chip.
- Carousel index.

Not allowed:
- Random circles behind balance.
- Decorative vector noise.
- Crypto-style patterns.
- Low contrast text over gradient.

Artwork must be backend-overridable through bank/card profile tokens, not Nova-local colors.
