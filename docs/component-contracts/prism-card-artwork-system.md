# Prism Card Artwork System

`SignalPrismCardArtwork` draws card faces from Signal Prism tokens.

Card face contains:
- Gradient background.
- Soft light reflection.
- Subtle inner highlight.
- Chip.
- Contactless mark.
- Bank logo area.
- Network mark.
- Masked PAN.
- Holder name.
- Expiry when policy allows.
- Virtual/physical indicator.

The visual system avoids stock card images. Backend may later provide gradient profile or artwork metadata.
