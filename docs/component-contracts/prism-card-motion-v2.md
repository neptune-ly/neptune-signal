# Prism Card Motion V2

Cards motion must explain relationships without becoming theatrical.

Approved motion:

- Carousel snap for browsing.
- Container-transform style detail transition when available.
- Fallback fade/scale/slide at 260-360ms.
- Secure data reveal uses calm fade/expand.
- Copy feedback uses a small inline state change.

Rejected motion:

- Repeating giant artwork on detail after carousel.
- 3D card flips for sensitive reveal.
- Continuous shimmer or pulsing.
- Slow cinematic transitions.

RTL:

- Directional movement follows reading/navigation direction.
- Numeric identifiers remain LTR.
