# Prism Floating Nav V2

`SignalPrismFloatingNav` is a floating control dock. It must not look like a tray, cradle blob, or strict Material navigation bar.

V2 changes:
- Removed the full-width hidden page background behind the dock.
- Reduced dock opacity and hard border visibility.
- Lowered center payment action closer to the dock.
- Reduced glow/shadow and active label weight.

Mode behavior:
- Dark: translucent deep navy/ink capsule with subtle edge.
- Light: frosted off-white capsule with soft shadow.
- OLED: near-black capsule with minimal luminance edge.

Cards tab remains only a stable destination in this pass.
