# Remote Card Artwork Contract

Prism card artwork is backend-ready.

Remote configuration can provide:
- scheme id
- scheme mark asset
- bank logo asset
- background style
- background asset URL
- primary, secondary, and accent colors
- gradient stops
- flat color
- layout template
- dark/light/OLED artwork variants

Official card network marks must come from official or bank-provided assets. Demo text placeholders are acceptable only in prototypes.
