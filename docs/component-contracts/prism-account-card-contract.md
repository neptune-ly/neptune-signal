# Prism Account Card Contract

`SignalPrismAccountCard` will own account hero presentation.

Required behavior:
- Prism default gradient with bank override support.
- OLED-safe variant.
- Balance mask/unmask motion.
- Proper formatted amounts and softer decimals.
- IBAN strip with strong readability.
- Status chips and account carousel indicators.

Nova supplies data only: account identity, amount, currency, state, IBAN, and actions.
