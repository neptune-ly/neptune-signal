Breaking Changes

Breaking changes include:

  • Renaming public tokens.
  • Changing type role meaning.
  • Changing component anatomy.
  • Changing navigation roots.
  • Removing required accessibility behavior.
  • Changing KMP API names after release.

Visual refinements that preserve names and behavior are minor or patch changes.
