# Compatibility

A product can claim Neptune. Signal compatibility when it follows the standard contract.

## Required

- Uses Neptune. Signal token model.
- Supports RTL and LTR.
- Uses standard type roles.
- Uses persistent root navigation where applicable.
- Uses standard status/result patterns.
- Uses standard account/card/banking row anatomy.
- Uses native motion or a faithful equivalent.
- Preserves accessibility rules.
- Preserves sensitive-data masking rules.

## Not Required

- Exact Neptune. colors in white-label products.
- Exact demo screen content.
- Exact prototype data.
- Exact HTML implementation.

## Compatibility Labels

```text
Signal Compatible
Signal Themed
Signal Inspired
```

Signal Compatible:

- Follows all required standard rules.

Signal Themed:

- Uses tokens and components but has product-specific changes.

Signal Inspired:

- Uses visual direction only and should not be treated as a compliant product.
