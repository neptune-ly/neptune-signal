# Mobile Banking Demo 0.1.0

The mobile banking demo is an implementation example of Neptune. Signal Standard 0.1.0.

It is not the standard itself.

## Included Flows

- Home.
- Accounts.
- Account details.
- Transfers.
- LyPay.
- Western Union.
- Cards.
- Vouchers.
- Services.
- NPT Alias.
- OpenWave consents.
- Support.
- Settings.
