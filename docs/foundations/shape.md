# Foundations: Shape and Elevation

## Radius

| Token | Value | Usage |
| --- | ---: | --- |
| radius.xs | 8 | Small controls, tags |
| radius.sm | 12 | Icons, compact chips |
| radius.md | 16 | Rows, fields |
| radius.lg | 20-22 | Cards, account surfaces |
| radius.xl | 24-28 | Result cards, major panels |
| radius.full | 999 | Pills, segmented controls |

## Elevation

Use elevation only to explain hierarchy or motion.

- Default rows: no heavy shadow.
- Pressed/lifted states: soft primary-tinted shadow.
- Modal/result cards: controlled shadow, no floating toy cards.

## Rule

Do not put cards inside cards unless the inner element is a real repeated item, modal, or framed tool.
