# Screenshot Guide

## Folder Structure

```text
docs/screenshots/prism/
  foundation/
  components/
  patterns/
  screens/
  personalities/
  platforms/
```

## Naming

Use:

```text
component-or-screen-appearance-locale-state.png
```

Examples:

- `service-hub-dark-ar-top.png`
- `cards-list-light-ar.png`
- `payment-ritual-oled-ar-success.png`

## Required Variants

- dark
- light
- OLED
- RTL Arabic
- LTR English where supported
- key personality presets

## Current Capture Strategy

Android emulator screenshots are acceptable until an automated gallery runner exists.
